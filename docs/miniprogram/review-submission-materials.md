# 开个小局小程序提审材料

更新时间：2026-06-11

## 小程序基础信息

**小程序名称：** 开个小局

**一句话介绍：** 在同城找一个轻松小局，和新朋友吃饭、喝咖啡、散步。

**短介绍（建议填小程序简介）：**
开个小局是面向年轻人的同城轻社交活动小程序。用户可以按城市发现饭局、咖啡、酒吧、散步等小局，活动前不开放联系方式，活动后双方互选才开放联系；部分活动由“局长”协助到场同步、破冰话题和 AA 确认，让陌生人见面更轻松、更有边界。

**长介绍（应用介绍/体验说明可用）：**
开个小局帮助用户在真实城市生活里发现轻松、低压力的同城活动。用户可选择城市和活动类型，查看活动详情、公开照片、活动亮点、预计费用和活动规则，并完成报名、候补排队、取消报名、到场同步、费用确认、活动反馈和互选。平台默认活动前不开放联系方式，活动后仅在双方互选后开放联系，降低陌生人社交压力。活动中的“局长”不是强组织者，只负责根据系统提示协助破冰、到场同步和 AA 状态确认。

## 建议服务类目

微信后台类目会随主体类型和平台规则变化，最终以小程序后台可选项为准。当前产品建议优先尝试以下方向：

1. **生活服务 / 休闲娱乐 / 活动服务**：最贴近同城线下活动发现与报名。
2. **生活服务 / 本地生活服务**：如果后台没有活动服务，可作为同城生活活动的备选。
3. **餐饮 / 点评与推荐**：仅适合作为饭局场景的补充类目，不建议作为唯一类目。
4. **工具 / 预约**：如果审核认为产品偏活动预约，可作为备选补充。

提交时不要把产品描述成婚恋、交友配对或私聊社交工具。推荐表达为“同城轻活动发现与报名”“活动后双向互选开放联系”。

## 隐私说明

**收集的信息：**
- 微信 OpenID：用于识别当前登录用户和报名状态。
- 用户昵称/头像：用于活动参与者展示、局长工作台和反馈互选。
- 城市选择：用于展示对应城市活动推荐。
- 活动报名信息：包括报名状态、候补状态、是否愿意担任局长。
- 活动流程信息：包括到场状态、AA 支付确认状态、活动反馈和互选结果。

**使用目的：**
- 展示活动列表、活动详情、我的行程和局长工作台。
- 处理报名、候补、取消报名、到场同步和 AA 确认。
- 活动结束后进行反馈与双向互选。
- 保障活动安全和基础信用规则。

**隐私边界：**
- 活动前不开放联系方式。
- 活动后仅双方互选成功才开放联系。
- 信用分不对外展示，仅展示等级。
- 用户可选择是否展示参加过的小局场次。
- 不展示用户精确实时位置；城市选择仅用于活动推荐。

**权限使用建议：**
- 当前版本不主动申请通讯录、精确定位、相册、麦克风等敏感权限。
- 如后续开启定位，应仅用于城市选择，并在隐私保护指引中明确用途。

## 用户协议/隐私政策入口

**入口位置建议：**
- `我的` 页面底部增加“用户协议”和“隐私政策”入口。
- 报名确认页规则区域增加“报名即表示你已阅读并同意用户协议、隐私政策”的说明。
- 小程序后台“用户隐私保护指引”按实际收集字段填写。

**用户协议摘要：**
用户需遵守线下活动规则，真实、友善、守时地参与活动；不得发布违法、骚扰、营销、欺诈或侵犯他人权益的内容；活动前不得绕过平台索取联系方式；如临近活动退出、爽约或恶意扰乱活动，平台可记录信用状态并限制部分功能。

**隐私政策摘要：**
平台仅为活动发现、报名、行程、局长协助、AA 确认、反馈互选等功能收集必要信息。未经用户同意，不会在活动前开放联系方式；活动后仅双方互选才开放联系。用户可通过“我的”页面查看展示设置和活动记录。

## 截图素材清单

建议准备 5 张审核/商店展示截图，尺寸以微信后台当前要求为准：

1. **发现页首页**：展示城市选择、搜索、分类、推荐活动卡片和平台规则。
2. **活动详情页**：展示活动照片、活动亮点、地点、费用、参与者预览和报名按钮。
3. **报名/行程页**：展示报名成功、到场同步、取消报名、费用确认。
4. **局长工作台**：展示局长任务、AI 话题卡、到场核准、AA 确认。
5. **我的页面**：展示等级、活动经历展示设置、最近想参加、参与过的小局。

**截图文案注意：**
- 避免出现“陌生人私聊”“快速脱单”“约会”等容易误解为婚恋/私密社交的表达。
- 强调“同城轻活动”“活动前不开放联系方式”“活动后双向互选”。
- 测试阶段切换按钮在正式截图前应关闭。

## 体验版说明

**体验路径：**
1. 打开发现页，选择城市：上海、北京、杭州、成都、深圳、广州。
2. 切换分类：推荐、饭局、咖啡、酒吧、免费活动。
3. 点击活动卡片进入详情页，查看照片、亮点、费用和规则。
4. 点击报名，测试普通报名和愿意担任局长两种状态。
5. 进入行程页，测试活动前、活动中、活动后状态。
6. 进入局长页，测试局长任务、话题卡、到场核准、AA 确认和反馈入口。
7. 进入我的页面，查看等级、展示设置和参与过的小局。

**测试账号说明：**
当前体验版使用微信登录对应的云开发用户身份。若需要复现固定状态，可先使用 `cloud/seed/*.jsonl` 数据导入云数据库，再重新编译体验版。

**已知测试开关：**
行程页和局长页有“测试阶段切换”按钮，用于审核前内部验证活动前/中/后流程。正式提审前应设置 `CITY_SOCIAL_ENABLE_STAGE_DEBUG=false` 后重新构建，隐藏该测试入口。
