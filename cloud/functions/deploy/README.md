# WeChat Cloud Function Deployment Folder

This folder contains WeChat Developer Tools uploadable cloud function packages.

Current status:

- Shared, locally tested TypeScript handlers live in `cloud/functions/src`.
- The first seed JSON files live in `cloud/seed`.
- Uploadable function folders are generated by `npm run generate:cloud-functions`.
- Each generated function package is self-contained with `index.js`, `runtime.js`, and `package.json`.

Generated function folders:

- `listActivities`
- `getActivityDetail`
- `signupActivity`
- `joinWaitlist`
- `confirmArrival`
- `confirmSettlement`
- `getJuZhangWorkspace`
- `respondJuZhangAssignment`
- `submitFeedback`
- `getFeedbackCompletionState`

After changing cloud runtime behavior, regenerate these folders before uploading:

```bash
npm run generate:cloud-functions
```

Then upload each function folder in WeChat Developer Tools Cloud Development. Do not edit generated `runtime.js` files directly; update `scripts/generate-cloud-functions.mjs` instead.
